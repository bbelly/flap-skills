# flap-skills

A collection of AI agent skills for [Flap](https://docs.flap.sh). Skills are compatible with AI coding agents including GitHub Copilot, Claude Code, OpenAI Codex, OpenClaw, and others.

## Skills

| Skill | Description |
|-------|-------------|
| [launch-bnb-token-on-flap](./launch-bnb-token-on-flap/SKILL.md) | Launch a Flap Tax Token V3 on Flap (BNB Chain), quoted against BNB or any other Flap-supported quote token |

## Usage

Each skill directory contains a `SKILL.md` file that defines the skill's behavior and reference files that provide step-by-step instructions.

To use a skill, point your AI agent to the `SKILL.md` file for the skill you want to use.
